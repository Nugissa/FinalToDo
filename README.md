#TO DO App для портфолио студентов
Учебное настольное приложение для простого упрвления задачами на
Java Swing.

## Возможности

- Создание списка задач, с возвожность исплользования 
рассширенных комментариев.
- Автоматическое указывание даты и времени всех важныъ операций 
внутри проложения.
